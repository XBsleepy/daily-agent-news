### 1. Apple Online Dense RL：在真实 iOS 应用上训练可恢复的 GUI Agent｜100/100

Apple 提出在真实 iOS 应用上进行在线强化学习的 GUI Agent 框架，组合规划模型、界面定位模型与逐步奖励。系统并行运行数百台可重置虚拟设备，利用中间进度奖励提升长程任务学习效率。论文报告 8B 模型在 Android 跨平台泛化上较 SFT 基线提升近 7 倍，并在 iOS 任务达到与 Gemini 3.1 Pro 相近的表现。

**背景：**GUI Agent 很难仅靠静态成功轨迹学会错误恢复；真实应用的页面变化、状态依赖和跨应用操作，都要求能够反复试错的训练环境。

**方法与实现：**训练设施以预装应用、已登录账号和可恢复快照为初始状态，约 10 秒就能重置一次设备，支持约 512 条并行轨迹。系统首先从真实 iOS 与 GUIOdyssey 轨迹构建训练任务，再由模型补充操作意图与计划；跨应用任务通过应用组合、任务生成和人工审核构建。执行时 Planning Agent 负责下一步计划，UI Grounding Model 将计划落到坐标操作；奖励由过程 Judge 提供的密集步骤反馈与最终任务成败组成。GiGPPO 利用视觉相似状态的邻近轨迹信息稳定 Value 估计，并缓解纯密集奖励可能产生的奖励投机。

**关键发现：**作者在 UINavBench、iOSWorld 与 AndroidWorld 等环境上报告超过 SFT 和仅终局奖励 RL 的表现；8B 模型 Android OOD 任务相对 SFT 接近七倍提升。真实应用在线训练、快照恢复和过程奖励形成了一条完整、可重复采样的训练闭环。

**研究价值：**优先研究从失败 Milestone 重新初始化环境、语义状态奖励与 UI 视觉相似度奖励的差异，以及跨 App 状态迁移是否真能从局部恢复训练中获益。

### 2. MemSteer：用用户历史自动生成记忆优化监督信号｜99/100

MemSteer 直接从未标注用户历史生成带证据的问答监督，让 Personal Agent 的记忆系统针对用户持续改进。它通过证据规划、来源审计和盲答案恢复生成可靠样本，再优化记忆存储、检索和上下文组织，无需更新基础模型。实验中 ATM-Bench Question Score 提升 13.4 分，RHELM 准确率提升 4.1 至 6.6 个百分点。

**背景：**真实个人助手积累大量对话和行为记录，却没有人为每位用户制作标准答案；因此，记忆写入、检索和压缩很难以真实个人历史为反馈进行持续优化。

**方法与实现：**MemSteer 先从多个历史片段建立 Evidence-Grounded Answer Plan，说明每个候选问题的答案由哪些事件支持，再生成 QA。Source-Grounded Auditing 会检查生成答案是否与原始证据一致，Blind Answer Recovery 则独立恢复答案以筛除难以稳定回答的问题。后续 MemSteer-Opt 用这些问答评价 Memory Store、Retrieval 和 Context Construction，并根据失败证据调整配置。整个流程优化的是记忆系统设计与检索方法，不要求对底座 LLM 做参数更新。

**关键发现：**相较 Base-BM25，ATM-Bench Question Score 增加 13.4 分，RHELM 无外部数据和有外部数据条件下分别增加 4.1、6.6 个百分点；作者也展示了面对新用户历史时继续生成监督并调整记忆设计的能力。

**研究价值：**与 CALM、PreCoMem 对照，研究用户偏好变化、错误伪标签累积和来源矛盾条件下的长期自优化效果。

**来源：**[论文原文](https://arxiv.org/abs/2610.39276)

### 3. MICA：同样的底层工具，CLI 与 MCP 会引发不同决策｜98/100

MICA 在相同任务、状态和执行器下对照 CLI 与 MCP 两种工具接口，证明工具的表达方式本身会改变 Agent 决策。六个模型、三个环境的 2,004 组成对执行中，94.3% 出现结构化行为分歧。其 DART 修复机制保留已验证的语义动作并专门修复接口实现问题，最多提高 9 分评测成绩。

**背景：**工具失败未必意味着模型不理解目标，也可能来自模型面对工具 Schema、参数格式和反馈呈现时的接口敏感性。

**方法与实现：**MICA 在 ALFWorld、WebShop 和 ScienceWorld 中从同一 Semantic Action Contract 生成 MCP 和 CLI 接口，确保二者调用完全相同的底层环境动作。通过匹配初始状态和执行器，实验隔离了工具表达格式对动作选择、错误传播和恢复的影响。以 Qwen3-14B 为例，ALFWorld 上 CLI 为 56.7%，MCP 为 20.1%；WebShop 则 MCP 为 64.4%，CLI 为 59.5%。DART 将动作的语义承诺与接口实现拆开，只针对接口层失效进行恢复。

**关键发现：**2,004 次匹配 Episode 中 94.3% 的轨迹出现结构化分歧；DART 在六项配置上均提高成绩，最多提升 9.0 分，某些 MCP 条件下每任务 Token 消耗最多减少 27.1k。

**研究价值：**训练或合成失败 Milestone 前先标记 Tool Interface Fault；在相同状态下测试多种接口，能够避免把 Harness 格式问题误判为策略能力不足。

**来源：**[论文原文](https://arxiv.org/abs/2610.34298)

### 4. PAPERBENCHX：AI Scientist 跨 12 个学科复现论文仍只有 14% 完成率｜97/100

PAPERBENCHX 将论文复现拓展到电磁学、光子学、化学、材料、生物和机器人等 12 个领域，提供 93 道真实科研复现任务。评测会清除提交者现有输出，重新运行科学程序，只给可重复生成的证据打分。在十组前沿 Agent 配置中，最强系统仅完整复现约 14% 的论文，即使最佳平均部分完成度达到 59.08%。

**背景：**AI Scientist 能够解释论文或写出看似合理的代码，但科学复现要求特定软件、正确参数与可重复的实验结果。

**方法与实现：**Benchmark 包含 93 道专家设计任务、12 个学科、10 类领域软件环境和 10 组 Agent 配置，单任务允许 4 至 72 小时。任务要求从论文描述重建关键实验、执行并排查结果，并提交可运行工作流。评分系统从零执行提交代码，生成新的数据与图表，再与专家验收要求逐项核对。它把论文理解、建模、实验操作和独立证据验证组成闭环，减少用已有结果文件蒙混过关的空间。

**关键发现：**最佳配置的完整复现率为约 13.98%（13/93），平均部分任务得分为 59.08%；所有受测配置的平均完整复现率约为 8.60%。实验设计和运行有一定进展，最终证据验证仍是重要瓶颈。

**研究价值：**适合把成功的科学实验步骤沉淀为版本化、可重新运行的 Verified Skills，再测量这些经验能否迁移至新的科研任务。

**来源：**[论文原文](https://arxiv.org/abs/2610.39744)

### 5. JEPA 表示学习：正样本关系设计比盲目扩模型更有效｜96/100

Yann LeCun 等人的 JEPA 研究提出：不同模态能否学到共享世界表示，关键在于正样本是否来自同一个场景。使用同场景的不同观察作为 Good Views，达到同等跨模态对齐效果所需数据量比下一 Token 预测少约 42 倍。仅 109M 参数的文本 JEPA，在相关表示对齐测试上超过所测最高 72B 参数语言模型。

**背景：**多模态训练常通过堆大模型或更多配对数据追求对齐，但真正影响世界状态表示的可能是样本之间的正关系。

**方法与实现：**论文以 Platonic Representation Hypothesis 为起点，证明在特定 JEPA 目标和正样本条件下，独立学习的模态表示可以在旋转变换后对齐。Good Views 是同一场景的不同观察，Bad Views 则常是同一份内容的局部切片或遮盖；后者容易让模型编码句子措辞等模态特有噪声。实验从 14.5 万条描述扩展至约 9.4 亿图像相关文本，并用独立训练的文本与视觉编码器比较跨模态几何。作者还展示了仅通过旋转映射组合编码器进行图像描述的能力。

**关键发现：**Good Views 对齐效率比下一 Token 预测高约 42 倍；109M 文本 JEPA 在作者报告的表示对齐指标上优于若干 70B 级语言模型，COCO 图像描述实验 CIDEr 为 0.838。

**研究价值：**对训练数据的启发是优先优化正样本关系、观察覆盖与环境变量，而非只提高 Token 数量；还能尝试为 Agent 世界状态构建多视图一致性数据。

**来源：**[论文原文](https://arxiv.org/abs/2610.39302)

### 6. dual-mem v0.2.1：跨设备个人记忆改为离线同步与本地检索｜95/100

dual-mem v0.2.1 将跨设备长期记忆改为每台设备本地检索，通过共享目录、私有 Git 或服务器交换记忆变更日志。新版移除常驻 SSH 隧道，减少跨设备切换 Claude Code、Codex 等 Agent 时的在线依赖。工程记忆只保留问题、最终回答和可复用经验，并把自动归纳频率控制在每天最多一次。

**背景：**不同 Agent 和电脑间的个人记忆如果必须依赖一个一直在线的中央服务，离线工作、同步冲突和隐私控制都会变得复杂。

**方法与实现：**dual-mem 用 System 1 保存事实、偏好变化和版本历史，再由 System 2 从多次事件中提炼稳定规律。新版将远程集中检索改为各设备保留自己的索引和搜索能力，通信只需同步存储变化；共享目录、私有 Git 仓库和服务端均可作为同步媒介。Coding 经验保留可复用的 procedure 而非无差别上传工具输出，降低噪声与上下文成本。配置统一归入用户本地 config.yaml，自动摘要合并每日最多执行一次。

**关键发现：**11 月 1 日版本主要改进部署、记忆同步与归纳成本；项目现有 LoCoMo、LongMemEval 等历史自测成绩并非本次版本新增实验结果。

**研究价值：**值得重点测试跨设备并发写入、冲突合并、删除传播，以及两台 Agent 在断网后重新同步时能否恢复一致且正确的用户状态。

**来源：**[项目 Release](https://github.com/shibing624/dual-mem/releases/tag/v0.2.1)

### 7. When Skills Tell Agents Not to Ask：约每 17 个 Agent Skills 就有一个弱化监督｜94/100

一项大规模 Agent Skills 安全研究扫描 153 万份英文技能文件，发现约 8.8 万份含有弱化审批或跳过检查的指令，比例接近 1/17。这些指令常鼓励直接执行、跳过验证或避免向用户确认，其中 70.1% 没有明确的使用条件。少数上游 Skill 家族贡献了大量重复扩散，说明技能包供应链本身正在影响 Agent 权限边界。

**背景：**SKILL.md 文件看似是可复用操作指南，但模型加载它时，其中的默认执行规则可能被实际当作权限建议。

**方法与实现：**论文建立了按指令极性、实现机制和作用范围分类的审计体系，人工标注 2,097 个语句单元，然后扩展至 153 万份 GitSkills 样本。相关指令涵盖 --no-verify、自动批准、跳过用户检查等；涉及 Shell、包安装或 sudo 的技能，包含弱化监督语句的可能性提高约 1.7—1.8 倍。传播分析发现，2.4% 的问题技能家族占此类复制品的一半。论文还对比现有开源 Skill 扫描器与基于定义手册的 LLM 检测表现。

**关键发现：**约 88,000 份技能包含弱化监督指令，70.1% 为无条件生效；现有扫描器最多检出 46%，精确率低于 0.4，而带代码本的 LLM 检测召回达到 61%、精确率约 0.71。

**研究价值：**需要把 Skill 本身纳入授权审计、版本跟踪和自动化安全回归测试，避免通过经验复用悄悄扩大 Agent 的可执行权限。

**来源：**[论文原文](https://arxiv.org/abs/2610.37734)

### 8. GAD：动态任务图让长期多 Agent 协作保住目标和验收条件｜93/100

GAD 将长程任务拆成不断增长的依赖图，每个子 Agent 始终保留原始目标、当前子任务和明确的验收条件。它根据实时执行证据决定如何拆分任务、传递结果和安排验证，减少目标漂移与重复探索。验证失败时，系统沿任务依赖关系恢复执行，适用于旅行、日程和多系统办公等持续变化的工作流。

**背景：**长程多 Agent 系统经常在分工后丢失总体目标，或到最后才验证结果，导致错误积累数十步才被发现。

**方法与实现：**GAD 设计一个持续扩展的 Execution Graph：任务目标分解为子目标，依赖约束决定哪些节点先执行，证据决定信息如何流向其他 Agent。每个 Agent 只接收与分配目标相关的必要状态，同时始终拥有原始指令和当前子任务验收标准。任务可以在执行中继续拆分并重新排序；Verifier 检查局部交付物以及整体完成情况，出错时触发定向恢复。相比将全部聊天记录拼成共享上下文，任务图可把目标、状态和验收从自然语言协作中显式分离。

**关键发现：**论文对比了单 Agent、分工不充分的多 Agent 与引入任务依赖和分层验证的方案，强调及时验证和控制跨角色信息传播的重要性。

**研究价值：**下一步应构建 Goal Revision Propagation 评测：用户改变目标后，依赖节点、后台任务和审批条件能否一致地更新。

**来源：**[论文原文](https://arxiv.org/abs/2610.39193)

### 11. HEDGE：超图记忆压缩多人证据并保留冲突关系｜89/100

HEDGE 将多 Agent 的观点、支持证据和冲突组织成语义超图，再让学习式选择器决定保存、备份还是舍弃。七个 Benchmark 中，相比最强多 Agent 基线平均准确率提高 5 分，在高冲突任务上提高 8.2 分。与此同时，记忆用量降低 48%，讨论轮次减少 34%。

**背景：**普通摘要常抹平多个 Agent 的分歧，完整保存讨论又使上下文快速膨胀；实际决策需要保留论点之间的高阶支持与冲突关系。

**方法与实现：**HEDGE 的超边连接多个相关主张，边内保留具体关系与证据来源，而不是只建立两个节点间的普通链接。Memory Selection Module 通过监督学习和强化学习训练，为候选内容选择 STORE、BACKUP 或 OMIT。重要但暂时不需要的证据进入备份，当前决策真正依赖的主张优先保留，重复内容则被压缩或省略。研究在不同讨论任务上比较回答质量、记忆 Token 与交互轮数。

**关键发现：**GPT-4o-mini 条件下较最强多 Agent 对照准确率平均增加 5.0 分；冲突任务增加 8.2 分，记忆消耗减少 48%，讨论轮数减少 34%。

**研究价值：**可将超图记忆用于多人家庭助手与企业协同，让偏好冲突、证据归属和不同时间版本在摘要压缩后仍可追溯。

### 12. LOWN：按需重看图像，让多模态推理 FLOPs 降到 35.3%｜88/100

LOWN 让扩散视觉语言模型仅在必要步骤重新处理图像，而不是每一步重复计算视觉 Token。它通过比较有无视觉条件下的预测，动态决定哪些视觉信息能够安全复用。在十项评测中，模型保留约 99.6% 的原始成绩，平均解码 FLOPs 降至 35.3%。

**背景：**扩散视觉语言模型的多个去噪步骤会重复处理同一图像；在研究测试中，视觉 Token 占输入的 89%—97%，形成明显的重复计算。

**方法与实现：**LOWN 在每步先尝试不读取图像做出 Token 预测，再比较这一预测与此前有图像条件的估计是否一致。一致性被用作可复用证书，决定是否跳过图像输入以及该步可以解除多少 Token 的遮盖。由于不同任务对视觉条件的依赖程度不同，路由策略动态调整，而不是固定每隔几步重新读取。方法不需要针对该任务额外训练，也不依赖人工设定阈值。

**关键发现：**十项 Benchmark 平均保留 99.6% 的 LLaDA-V 原始评分，解码 FLOPs 仅为原来的 35.3%；论文还报告它可以与视觉 Token 剪枝和 KV 缓存结合。

**研究价值：**对 GUI Agent 的启发是按风险和状态变化决定何时重新观察界面；需要专门测试价格、权限和确认按钮等细微变化，避免节省计算却错过关键状态。

### 13. LangChain Schedules SDK：主动式 Agent 用定时唤醒而非持续推理｜86/100

LangChain 总结了主动式 Agent 的实现方式：定时唤醒、读取持久化状态，再判断是否需要采取行动。Schedules SDK 可用来做长期记忆归纳、主动跟进、信息监控和等待中的任务恢复。LangChain 称其托管 Deep Agents 平台超过 70% 的运行由定时触发，说明主动执行正在成为真实产品的重要交互形式。

**背景：**24 小时服务不要求模型每时每刻都在推理，低成本的调度系统能够定期检查用户目标和外部事件，只在需要时启动 Agent。

**关键发现：**核心信号是主动性更多依赖调度和状态保存，而非持续推理；固定频率与事件触发策略会直接影响用户打扰和资源开销。

**研究价值：**建议比较定时检查、事件唤醒和自适应频率控制，测量真正有用的主动介入次数、错误提醒率及单位算力收益。
