### 1. Google DeepMind：Gemini 4 多 Agent 发现 Lean 可验证的高效量子算法｜100/100

DeepMind 11 月 23 日公开 Gemini 4 多 Agent 优化量子算法的研究及开源验证框架。团队借助 Lean 验证候选程序的正确性与资源成本，报告聚变相关电路计算成本降低 11.8 倍、光化学降低 8 倍、酶模拟降低 2.5 倍。结果展示了多 Agent 搜索与形式化验证结合的科研发现路径。

**背景：**论文 11 月 6 日首次提交，11 月 23 日发布官方研究解读与开源资源。

**技术机制与实验：**研究人员定义问题，独立 Agent 团队提出程序并证明其符合约束，再通过共享知识库和定期交流复用成果。聚变电路所需逻辑量子比特由 5650 降至 4338，反正弦计算的资源成本改善达 290 倍。这里的收益是数学验证的电路资源估计，并非真实量子硬件运行测量。

**核心发现：**多团队并行探索、共享经过验证的中间结果、统一可计算成本，是可迁移的科研搜索模式。

**研究价值：**适合研究 AI4AI 的可验证搜索、跨团队经验共享和科学任务的过程级奖励。

**首次提交 / 官方发布：**2026-11-23

**原始来源：**[Google DeepMind 官方研究](https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/) · [原始论文（11 月 6 日首次提交）](https://arxiv.org/abs/2611.09822)

### 2. RemoteEvolver：通过工具与技能进化实现遥感 Agent 持续学习｜99/100

RemoteEvolver 固定基模权重，通过外部 Harness 扩展遥感工具与可复用技能。面对工具齐全和部分缺失的任务，两个基准上的平均准确率相对初始状态分别提高 8.18 和 23.86 个百分点。它把执行反馈转化为跨任务能力积累，而非仅仅重排固定工具。

**背景：**论文研究可持续扩展能力的地球观测 Agent。

**技术机制与实验：**系统在发现能力缺口时获取所需专业工具，把验证成功的任务轨迹提炼为持久技能，再用于后续规划。在 Earth-Bench 与 OpenEarthAgent-Bench 的两种工具配置中，相对既有最强方法的平均收益分别为 6.77 和 17.10 个百分点。

**核心发现：**工具缺失时，外部能力扩展和技能复用的价值更突出。

**研究价值：**可作为 Harness 自进化、技能回归测试及长期运行 Agent 的参考。

**首次提交 / 官方发布：**2026-11-20

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.27110)

### 3. From Acting to Learning：用优化器感知的经验选择训练持续学习 Agent｜98/100

研究比较九种成功轨迹选择策略，训练 288 个 4B Student 并统一评测。梯度感知选择在两个经验池中达到 81.45% 和 73.19% 的成功率，比全局随机选择高 8.25 和 5.96 个百分点。结果说明成功经验的学习价值并不相同，样本选择本身是持续学习的重要变量。

**背景：**研究将经验选择独立出来，考察不同初始化与采样随机种子下的稳定收益。

**技术机制与实验：**实验固定经验池与训练预算，比较九种选择器、八个初始化和两个采样种子。在相同数据自由度下，相对高 NLL 选择的增益为 4.10 与 4.05 个百分点；保留任务组上的独立复现实验中，相对随机及高 NLL 的收益分别为 7.03 和 5.03 个百分点。

**核心发现：**训练价值取决于经验与 Student 优化过程的匹配，而不只是奖励或难度。

**研究价值：**适合设计 Agent RL/SFT 数据选择、在线经验回放和自适应课程。

**首次提交 / 官方发布：**2026-11-20

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.27159)

### 4. OceanCoder：三层工程验证驱动海洋仿真代码生成与 GRPO｜97/100

OceanCoder 基于 Qwen3-8B 构建海洋工程仿真专用模型，并合成覆盖 12 类任务的 12000 条已验证 SFT 样本。三层验证器检查工程输入、分析任务完成情况及输出合理性，并为 GRPO 提供分级奖励。Pass@1 从基模的 0% 提升到 SFT 后的 46.77%，再经 GRPO 达到 51.43%。

**背景：**研究解决代码能运行但不满足真实工程约束的问题。

**技术机制与实验：**数据构造流程先覆盖工程任务类型，再检查参数、约束、数值分析是否执行以及结果是否合理。基准还包含分布外任务和真实工程案例，形成专业领域训练与验证闭环。

**核心发现：**代码执行成功不足以评价工程建模，专业规则可用于构造更有效的训练奖励。

**研究价值：**可迁移至科学计算、有限元、EDA 等多阶段可执行任务合成。

**首次提交 / 官方发布：**2026-11-19

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.26333)

### 5. AI Agents Redesign Engineering Parts：GPT-6 Astra 在 1650 维 CAD 空间优化支架｜97/100

GPT-6 Astra 在约 1650 个 CAD 设计参数中迭代修改镁合金支架，预算仅为 15 次非线性仿真。论文报告目标应变指标下降 32%，同预算下工业形状优化器约改善一成。更高保真度的独立仿真还验证了早期设计方案的减损效果，展示了高维工程设计中的 Agent 价值。

**背景：**真实工程优化同时受高维参数、昂贵求解和结构级改动约束。

**技术机制与实验：**Agent 每次提案均经 CAD 构建、网格划分及包含接触和塑性的仿真，再依据完整结果调整方案。较早的方案在完整部署模拟中应变降低 14%，局部最严重损伤指标降低 63%。

**核心发现：**利用模型的工程知识缩小搜索空间，可在有限仿真预算内找到有价值的结构级改动。

**研究价值：**适合研究科学 Agent 的预算约束搜索与多保真度验证；该研究是仿真实验而非临床验证。

**首次提交 / 官方发布：**2026-11-19

### 6. ChatAtom：多 Agent 打通分子动力学模拟、执行与分析｜96/100

ChatAtom 将自然语言请求转为完整分子动力学任务，覆盖实验规划、脚本生成、执行、可视化与解释。LAMMPS 和 OVITO 模块采用生成与审查分工，并通过 HPC 模块提交远程作业。论文用脚本基准、裂纹扩展案例及闭环研究检验该工作流，提供科学 Agent 端到端任务的设计样例。

**背景：**传统分子动力学任务需要多个专业工具和人工脚本编写。

**技术机制与实验：**协调 Agent 负责研究规划，模拟与可视化模块独立审查脚本，执行模块处理远程算力，分析模块解释产物。浏览器可实时展示本地运行数据和画面，系统也支持通过加载技能扩展功能。

**核心发现：**完整任务交付可以同时保留运行状态、可视化证据与脚本审查。

**研究价值：**适合作为 Terminal-Bench-Science 类任务的流程及交付物设计参考。

### 7. Self-verifiable LLM-driven science：以 Lean 验证科学论证链｜96/100

研究提出将科学推理拆为可审阅的前提和可由机器验证的演绎过程。Agent 给出候选假设，人类确认实验事实、理论及额外假设，再由 Lean 检查形式化论证。多个示例说明该机制可将科学结果的核查从重做整条推理转向审查关键前提。

**背景：**论文把形式化数学的验证范式延伸到非数学科学研究。

**核心发现：**将假设审阅与逻辑验证分开，有助于形成可追溯的科学发现流程。

**研究价值：**适合研究科学任务规格、证明奖励、人机协同与可复现证据。

### 8. Correct Precedents：正确历史决策也会诱发端侧 Agent 权限错误｜95/100

研究发现端侧 Agent 会把先前正确的授权决定错误迁移到仍受限制的新对象。13 个开放权重模型中观察到该现象，最受影响的模型一次正确先例即可使安全率约减半。配对决策蒸馏通过 LoRA 将弱受影响教师的判断传递给学生，实验中的安全率恢复到接近 100%。

**背景：**云端模型与端侧 Agent 协作时，端侧判断常承担个人数据与执行权限的最后检查。

**技术机制与实验：**作者通过历史干预实验观察到，Agent 倾向复用先前决定而非检查当前对象的权限状态。配对蒸馏强化不同授权状态的区分，不需额外提示或额外推理调用。

**核心发现：**历史上下文无错误并不意味着后续权限决策正确。

**研究价值：**可用于 Personal Agent 的逐对象授权、跨会话权限评测和安全后训练。

**首次提交 / 官方发布：**2026-11-20

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.27216)

### 9. MSRyzen：可追溯谱图证据的蛋白质组学 Agent｜95/100

MSRyzen 将自然语言转换为蛋白质组学分析 DAG，自动调用工具并调优参数。在四个公开 top-down 数据集上，固定 1% 错误发现率时，自动调参使蛋白质形态鉴定数比默认参数提高 3.6% 至 15.8%。平台同时提供谱峰、序列覆盖与鉴定指标的交互证据。

**背景：**质谱蛋白质组学分析依赖复杂的软件组合与专业参数。

**技术机制与实验：**系统支持 bottom-up 和 top-down 流程，通过标准化可调用接口接入外部软件，并依据定量指标及用户目标调整参数。输出界面让研究者把整体鉴定质量追溯到具体谱图与序列证据。

**核心发现：**科学 Agent 的优化结果应同时交付可检查的原始证据和评价指标。

**研究价值：**可作为科学工作流技能、证据级评分和专业参数搜索的参考。

**首次提交 / 官方发布：**2026-11-20

### 10. Weight-space Programming：用机制解释与权重编辑修复粒子物理模型｜95/100

粒子物理基础模型被发现对加入软中性粒子异常敏感，违反红外安全性要求。研究比较稀疏自编码器引导的编辑与 Agent 直接修改权重两种方案，后者仅使用 50 次模型查询且无需梯度。两种方法均消除了绝大部分缺陷，并尽量保留原模型的其他响应。

**背景：**工作针对喷注分类基础模型中不符合物理规律的行为。

**技术机制与实验：**机制分析定位相关注意力头，并将缺陷与预训练数据的不同重建阈值联系起来。作者分别移除三个相关潜在方向、采用 Agent 进行权重编辑；修复效果还迁移至其他信号类别和下游任务。

**核心发现：**针对明确缺陷的局部模型编辑有可能比全量微调更节省参数改动。

**研究价值：**适合 AI4AI 模型诊断、可验证修复及编辑后能力回归研究。

**首次提交 / 官方发布：**2026-11-20

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.27079)

### 11. BioEmu2：统一静态结构、平衡采样与分子动力学的生成模型｜94/100

BioEmu2 用生成模型统一生物分子结构预测、平衡构象采样和时间演化。它支持蛋白质、核酸、配体等多组分系统，在测试体系中相对 MD 参考的自由能误差接近 1 kcal/mol。其高效采样能力可成为科学 Agent 执行分子模拟时的候选工具。

**背景：**结构预测之后，分子运动与相互作用仍是理解功能的重要难题。

**技术机制与实验：**模型利用实验与合成结构及大量 MD 数据训练，支持大复合物预测、构象约束和用户定义的偏置势控制。论文报告采样比传统 MD 快多个数量级，并评估长时间尺度轨迹与结合动力学。

**核心发现：**一个模型可同时支持结构、分布和时间演化预测。

**研究价值：**有助于构建科学 Agent 的分子工具生态和模拟预算自适应任务。

### 12. Actions Speak Louder than Words：Web Agent 的行为隐私泄漏｜94/100

研究发现即使 Web Agent 不显式发送私人文本，其浏览选择和行为模式也可能泄露用户上下文。实验中用户画像重建的平均 F1 达 0.80，而常见内容级防御改善有限。研究提出选择混淆式检索，将敏感选择留在本地，降低该类风险。

**背景：**联网个人助手的行为本身可能暴露隐私，而非仅通过输出文本。

**技术机制与实验：**论文在多个 Agent 和模型、问答与多轮任务数据上评估这一风险，并提出在本地资源快照内进行选择的缓解思路。实验报告防御后泄漏重建 F1 降至 0.39，无需额外 LLM 推理。

**核心发现：**浏览行为需要作为独立的隐私评测维度。

**研究价值：**适合研究 Personal Agent 的隐私隔离、连接器设计和端到端信息流审计。

**首次提交 / 官方发布：**2026-11-20

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.27046)

### 13. Observed, Curated, Reused：临床评测中的时间与来源泄漏｜94/100

研究追踪 6503 例临床案例与六个历史 HPO 版本，发现案例来源论文可能进入评测使用的知识库。主要诊断排序器的 MRR 在来源纳入前为 0.26，纳入后升至 0.84，移除相关证据后降至 0.05。结果强调专业 Agent 评测应同时隔离测试样本、证据来源与知识可用时间。

**背景：**真实医学记录往往只反映医生当时观察或记录的部分信息。

**技术机制与实验：**研究利用 HPO 知识库中可识别的来源引入事件，比较引入前后及反事实移除相关证据的诊断排序表现。其他排序器也呈现相近趋势，说明部分评测高分可能来自知识库对同源证据的复用。

**核心发现：**时间冻结与来源级去重比只检查文本重复更能揭示专业评测泄漏。

**研究价值：**可迁移到医学、法律、SRE、科学研究任务的数据治理和环境回放。

**首次提交 / 官方发布：**2026-11-20

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.27301)

**研究价值：**适合构建跨视觉、物理与工程验证的科学 Agent 基准。
