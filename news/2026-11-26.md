## P0｜重点进展

### 1. CoT-Proxy：无需隐藏思维链的长程 Agent 策略蒸馏｜100/100

CoT-Proxy 仅使用教师可见动作及推理摘要蒸馏长程策略，无需读取隐藏思维链。蒸馏 GPT-5.6 Luna 后，Qwen3-4B 在 AppWorld 的成功率从 7% 升至 48%，在 SWE-bench Verified 从 3% 升至 28%。这为闭源教师驱动的 Agent 后训练提供了新方案。

**背景：**闭源前沿模型往往无法导出完整推理轨迹。

**技术机制与实验：**训练阶段留空学生的推理块，并用学生自身生成的回放缓冲区计算 KL 约束以控制漂移；教师摘要可以作为额外训练信号。

**核心发现：**学生在推理开启时可用自己的推理风格执行学到的动作策略。

**研究价值：**可用于低成本长程策略蒸馏与轨迹数据设计。

**首次提交 / 官方更新：**2026-11-24

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.33148)

### 2. Google DeepMind：Antigravity 发布 Mass Spec Skills｜99/100

Google DeepMind 发布用于串联质谱分析的 Antigravity 技能插件，将原始谱图转换为候选分子结构与证据报告。Agent 可执行分子式推断、异构体排序和碎片验证，轻量模型搭配技能也能达到前沿检索水平。该插件展示了专业科学工具与 Agent 工作流的结合。

**背景：**质谱信号的结构注释仍需要专业知识及工具协作。

**技术机制与实验：**技能串联谱图预处理、候选结构检索和模拟碎片等操作，输出供化学家复查的证据。官方同时宣布向符合条件的 10,000 名科学家提供为期六个月的最高使用层级。

**核心发现：**专业技能与结构化证据能减少单纯依赖基模能力的需求。

**研究价值：**值得跟踪可复用科学 Skill 与科研工作流产品化。

**首次提交 / 官方更新：**2026-11-25

**原始来源：**[Google DeepMind 官方发布](https://deepmind.google/blog/interpreting-mass-spectra-with-google-antigravity/)

### 3. RecurSciBench：独立评估科学 Agent 的递归自我改进｜98/100

RecurSciBench 从原始数据集自动构造可执行科学任务并检查科学有效性。研究在四个领域比较四套 RSI 系统进化前后的独立任务表现，发现平均收益可与单任务退化并存。跨领域迁移甚至可能在源领域未观察到提升时发生。

**背景：**自进化系统需要独立于训练经历的验证任务。

**技术机制与实验：**RecurSciPipe 自动构造科学建模与分析任务，并按同类型、跨类型、跨领域的方式测试迁移。

**核心发现：**总体提升不足以反映所有任务的回归；迁移能力和源任务收益需要分别度量。

**研究价值：**适合作为 RSI 的独立验证和回归评测框架。

**首次提交 / 官方更新：**2026-11-24

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.32508)

### 4. Leto：以实际回答效用驱动长期 Agent 记忆｜97/100

Leto 将记忆目标从忠实复述历史转为提升未来回答质量，并通过结果反馈改善记忆选择。相较最强对照系统，PrefEval 准确率高 16.3 个百分点，PERMA 任务完成率高 3.1 个百分点。该研究为长期个人助手的记忆优化提供了可测量目标。

**背景：**语义相关的历史片段不一定对当前任务有帮助。

**技术机制与实验：**系统保存可追溯的历史索引，在请求到来时重放相关背景，并根据最终回答的效用修正选择；研究比较六套记忆系统、五个基准。

**核心发现：**MemoryArena 五个环境平均表现领先，且随任务链深度增长的收益更明显。

**研究价值：**适合设计长期上下文、记忆反馈和个性化系统。

**首次提交 / 官方更新：**2026-11-24

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.33005)

### 5. Delegent：前沿模型与本地小模型协作降低 Agent 成本｜97/100

Delegent 让前沿模型负责总体任务，将代码调查、测试和检索等局部工作委派给本地小模型。27B 小模型参与时，长程 Coding 的前沿模型费用下降 67%，Agentic Search 费用下降 59%，任务表现未降低。该架构不需要额外训练路由器。

**背景：**前沿模型每步重读上下文并处理简单子任务会提高执行成本。

**技术机制与实验：**基于 Claude Code 的 Harness 保留前沿模型主导权，局部代理处理集中且明确的工作；2B 小模型也可减少约 66% 的 Coding 前沿调用费用。

**核心发现：**收益来自减少前沿模型重复执行的辅助工作，而不是将整项任务交给较弱模型。

**研究价值：**可用于本地协作、成本优化与多 Agent 架构。

**首次提交 / 官方更新：**2026-11-24

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.33098)

### 6. ShellBench：真实日常任务中的模型与 Harness 对比｜96/100

ShellBench 从逾千万条用户请求提炼出 100 项日常任务，覆盖杂乱文件与相互竞争的数据来源。研究组合 12 个模型、5 种 Harness 和 3 档推理强度，累计 53,100 次运行。结果显示在该基准上模型选择比 Harness 选择更影响成功率，领先三款模型差距仅 1.1 个百分点。

**背景：**日常工作空间的任务比孤立编程题更贴近普通用户需求。

**技术机制与实验：**任务同时考察正确性与安全性；GPT-6 Astra 成功率 62.5%，GPT-6.1 Sol 为 61.4%，后者估算单次 token 成本约为前者六分之一。

**核心发现：**所测 Harness 的平均 pass@1 处于 42.9% 至 45.2% 区间。

**研究价值：**可用于个人 Agent 配置选择和成本效果权衡。

**首次提交 / 官方更新：**2026-11-24

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.32946)

### 7. AIChipBench：有状态 AI 加速器设计的 Coding Agent 基准｜96/100

AIChipBench 要求 Agent 实现可综合的量化模型解码器 RTL，并检查每一步的输出与内部状态。9,136 次尝试显示，直接反馈首个状态偏差比仅反馈输出更有效，验收率提升 25.0 至 46.9 个百分点。新序列复测揭示部分通过开发测试的设计仍存在隐藏状态错误。

**背景：**硬件解码器的状态错误可能在多个 token 之后才暴露。

**技术机制与实验：**任务包含 Qwen、Gemma 和 Llama 等解码器，冻结设计后使用隐藏序列、复位、存储停顿和综合测试进行验收，并设置性能优化赛道。

**核心发现：**在新增测试条件下，69 个此前验收设计中有 45 个在原测试所要求的 32 步内失败。

**研究价值：**为可执行硬件环境、状态级奖励和 AI4AI 工程评测提供参考。

**首次提交 / 官方更新：**2026-11-24

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.33093)

### 8. CANON：独立验证器驱动的多环 Feynman 积分构造｜96/100

CANON 让 Agent 在多个数学方法之间选择并调用工具，搜索多环 Feynman 积分的规范基底。独立程序负责验证候选结果，并在失败时要求 Agent 重试。研究在若干二环和三环积分族上展示了这一可审计工作流。

**背景：**规范微分方程方法中的基底构造缺乏普遍适用的单一策略。

**技术机制与实验：**框架维护长期搜索状态，支持多个子 Agent 协同更新基底候选和微分方程系统；验证与生成职责分离。

**核心发现：**专业工具、状态管理与确定性检查可以构成可复用的数学搜索闭环。

**研究价值：**值得借鉴到其他可符号验证的科研任务。

### 9. PhyEvo-Mic-RSI：显微镜分析中的可继承自进化工具｜95/100

PhyEvo-Mic-RSI 将专家修正转化为经过测试、可继承的代码算子、参数和路由规则。在 10% 面积预算下，跨材料界面覆盖率从 5.13% 升至 72.11%。这一机制展示了科研专家经验如何沉淀为持续改进的工具能力。

**背景：**原子缺陷和界面的图像判读常依赖研究人员经验。

**技术机制与实验：**结合物理先验与专家反馈，在固定预算内验证代码修改并按版本继承；在未见研究的图像上也尝试优化纳米颗粒分离。

**核心发现：**系统可以把一次性的人工纠正转化为后续任务可复用的执行能力。

**研究价值：**适合研究科研工具的版本化自进化和专家反馈积累。

### 10. Within-task Hazards：重新审视 Agent 长任务失败风险｜95/100

研究指出，仅凭任务时长与成功率的横截面曲线无法识别任务内部的失败风险变化。对相同任务重复运行，可以在特定统计假设下进一步识别风险趋势。结果提示不能把 time-horizon 曲线直接解释成 Agent 越执行越稳定。

**背景：**不同任务难度的混合会掩盖任务内部的风险结构。

**技术机制与实验：**作者分析单次与两次均成功的曲线位移，讨论可识别性及潜在偏差，并使用 METR 公开运行级数据检验模型。

**核心发现：**重复运行比仅增加横截面任务样本更直接地补充风险识别信息。

**研究价值：**可用于长程 Agent 的可靠性度量与实验设计。

**首次提交 / 官方更新：**2026-11-24

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.32415)

### 11. Agent Evaluation Without Ground Truth：无完整真值的统计评测｜94/100

### 12. Multi-agent Meta-solvers：自动搜索 Pareto 最优 PDE 求解器｜94/100

多 Agent 框架通过提出、批评、实现和执行评估进化混合线性求解器。它在六项指标上搜索 Pareto 前沿，而非只返回单一最优配置。两项三维问题中最佳方案的在线求解时间较基线分别改善 2.3 倍和 3.0 倍。

**背景：**离散 PDE 的求解器设计涉及问题特定的数值方法组合。

**技术机制与实验：**系统组合 Krylov 方法、预条件器、分块分解和神经算子，并在小型开放权重模型上运行遗传搜索。

**核心发现：**四类问题的实验显示多角色协同与可执行评估有助于搜索有效配置。

**研究价值：**为 AI4AI 和自动算法发现的多目标反馈设计提供参考。

### 13. RecordRoute：定位关键错误记录后诊断 Agent 失败｜93/100

RecordRoute 先对轨迹记录排序，定位决定性失败步骤，再使用局部文本与元数据判断错误类型。固定责任主体和步骤预测时，局部诊断联合准确率为 77.47%，高于整条轨迹诊断的 69.28%。该方案可用于训练后调试与失败轨迹分析。

**背景：**长轨迹中无关事件容易干扰错误归因。

**技术机制与实验：**记录排序使用词语与字符特征，选中记录提供责任主体和步骤，局部信息用于模式分类；测试包含注入错误与自然失败。

**核心发现：**将定位结果用于后续诊断可提升错误归因质量。

**研究价值：**适合构建自动化失败分析和针对性后训练数据。

**首次提交 / 官方更新：**2026-11-24

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.33022)

### 14. Clinical Agent Judge：临床动作评测需要真实证据｜93/100

研究向经过验证的临床 Agent 轨迹注入八类错误，共形成 416 条故障轨迹。只给最终答案时，Judge 无法识别不改变答案的执行错误，并误报 56% 的正确轨迹。完整病历证据结合规则检查器可识别 97% 的注入故障。

**背景：**临床任务的最终输出可能掩盖执行过程中的风险。

**技术机制与实验：**实验基于 MedAgentBench，比较六款开放权重 Judge 在不同证据输入下的辨别能力，并与规则检查器结合。

**核心发现：**实际环境证据比仅展示 Agent 推理或最终文本更有助于错误判定。

**研究价值：**对医疗工作 Agent 的过程审计、奖励与安全评测具有参考价值。

**首次提交 / 官方更新：**2026-11-24

**原始来源：**[arXiv 原始论文](https://arxiv.org/abs/2611.33012)

### 15. Science Gateway Agent Skills：将前沿模型技能迁移至开放模型｜92/100

研究将前沿模型编写的 Pegasus 科研工作流技能迁移至开放权重模型。在真实 science gateway 上评测 21 款模型和 17 项任务，通过反复测试反馈改进技能。表现较好的开放模型工作流构建得分为 0.76，Claude 为 0.82。

**核心发现：**真实系统评测还需要区分平台故障和模型失败，并控制实验权限。

### 17. PathGrad：以实验动力学观测优化机器学习力场｜89/100

### 19. AgenticAI-Control：融合气象预警与工程知识的排水控制｜87/100

两个 LLM Agent 将多源气象预警与排水工程知识融合，生成实时控制策略。基于十次真实降雨事件的仿真实验中，积水与溢流合计体积较规则基线减少 69.1% 至 90.6%。标准化提示和模块化流程缩小了四款模型之间的表现差异。

**背景：**稀疏传感器难以充分反映城市排水系统的实时状态。

**技术机制与实验：**系统在中国东部一处合流制排水区的仿真中评估外部预警融合与控制决策。

**核心发现：**模拟结果展示 Agent 处理异构信息的潜力，并不等同于已实际部署。

**研究价值：**值得关注有领域约束和仿真验证的工作 Agent。
